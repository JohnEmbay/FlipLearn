🎨 How the Website Looks (The Layout)
The screen is split into three main parts:

The Top Bar: Your control center. It has search, quick menus for subjects, and buttons to log in or create a new deck.

The Left Sidebar: Your menu. This lets you quickly switch between different pages (like the Dashboard, Learn Mode, or Stats). It also shows your current Level and XP.

The Main Middle Area: The workspace where the action happens. It automatically changes depending on what menu item you click.

⚙️ How It Works (The Core Features)
1. The Main Dashboard (Flashcards Page)
What it is: The homepage where you see all available card decks.

How it works: Each deck looks like a mini-box showing the topic (like AP Biology or Conversational Spanish), the number of cards, and who made it. Clicking any deck starts the review game.

2. Learn Mode (Creating & Flipping Cards)
Flipping Cards: You see a digital card. Clicking it flips it around with a smooth animation to show the answer or definition.

Adding Your Own Words: There is a form right below the card. Type in a word (e.g., a Spanish vocabulary word), type the definition, select a deck, and click Save. It instantly adds it to your collection.

Wiping Data: If you want to delete all cards and start completely fresh, there is a Wipe Active Cards button.

3. The Review Game Mode
How it works: When you play a deck, the screen goes dark so you can focus. You are shown a word and four multiple-choice answers.

The Rules: You have 30 seconds per question.

If you guess correctly, the card glows green and your score and streak go up.

If you guess wrong, the card shakes, turns red, and highlights the right answer.

4. Progress Stats & The Reset Button
Tracking: The website tracks your cards learned, accuracy percentage, and game streaks. It displays this data in clean, easy-to-read charts.

Separate User Tracking: The app starts at exactly 0 for new users so your stats aren't mixed up with anyone else's.

The Reset Button: If you want to clear your scores, history, and streaks back to zero, just click the 🔄 Reset Progress Data button found on the dashboard or stats page.
